# Accessibility Review Skill

Use this skill when:
- Creating or editing dashboards
- Building forms
- Updating navigation
- Designing tables
- Adding status badges or charts
- Creating driver/passenger mobile views

## Checklist
- Every interactive element is keyboard reachable
- Focus styles are visible
- Inputs have labels
- Errors are explained in text
- Tables have clear headers
- Color is not the only indicator of meaning
- Contrast is sufficient
- Modals and drawers are accessible
- Mobile tap targets are large enough
