# Dashboard UI Skill

Use this skill when working on:
- Admin dashboard
- Transport dashboard
- Compliance dashboard
- Fuel dashboard
- Garage dashboard
- Finance dashboard
- Dashboard cards, charts, widgets, status boards

## Goals
- Show the most important information first
- Make alerts and pending actions easy to see
- Keep dashboard layout consistent across modules
- Support drill-down from KPI to table to detail page
