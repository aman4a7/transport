# RBAC Security Skill

Use this skill when working on:
- roles
- permissions
- policies
- guards
- access checks
- audit logging
- sensitive actions

## Goals
- Apply least privilege
- Separate duties
- Enforce backend authorization
- Combine RBAC with policy rules
- Make permission changes auditable
